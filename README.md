# 🍔 Foodzie

Foodzie is a **full-stack food delivery web application** built using the **MERN stack (MongoDB, Express.js, React.js, Node.js)**. Inspired by platforms like **Zomato** and **Swiggy**, Foodzie allows users to browse restaurants, explore menus, and place food orders online with a smooth and modern user experience.

The platform also includes **secure online payments via Razorpay** and a **separate admin interface** to manage restaurants, food items, and orders efficiently.

---

## 🚀 Features

### 👤 User Side
- Browse restaurants and food menus
- Add items to cart
- Place orders online
- Secure payment integration with **Razorpay**
- Responsive and modern UI

### 🛠 Admin Panel
- Add / update / delete food items
- Manage restaurant menu
- Track and manage user orders
- Separate admin dashboard
